# Dolphin Brain

A meme identity forming on Robinhood Chain. Dolphin Brain is built around a simple idea: publish what's real, mark what isn't, and let the project earn attention instead of manufacturing it.

## Overview

Dolphin Brain pairs a character — calm, observant, quick to notice patterns in noisy water — with a site and a codebase that practice what the character implies. Nothing here is dressed up to look more finished than it is. Where a fact exists, it's dated and sourced. Where it doesn't, the interface says so instead of filling the gap with a placeholder number.

This repository holds the supporting documentation for the project. The live site lives at [dolphinbrain.app](https://dolphinbrain.app).
